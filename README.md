# CampusHelp — University Student Service Request Portal

**Assignment:** GitHub-Based Project Management • **Format:** individual submission (as confirmed by the student) • **Planned duration:** 10 working days

CampusHelp is a **browser-only academic prototype** for submitting and tracking student service requests. It demonstrates six required capabilities: student request submission, category/priority, unique request IDs, administrator assignment, status updates, and a dashboard.

## Project scope
This assignment focuses on **planning, executing, monitoring, controlling, and closing** a software project using GitHub. A production-ready system is not required.

## Demonstration
Once the prepared `prototype/` files are added:
1. Open `prototype/index.html` in a modern browser and submit a fictional student request.
2. Copy the generated `CH-...` ID and look it up in `prototype/track.html`.
3. Open `prototype/admin.html` in the same browser/profile and change the assignment/status.
4. Return to the tracking screen and verify the update.

**Prototype limitations:** Records are stored only in the browser's localStorage. There is no backend, real authentication, real email/SMS, or live university integration. Do not input real personal data.
