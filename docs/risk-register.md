# CampusHelp Risk Register

Qualitative probability and impact are Low, Medium or High. **Risk owner for all items:** solo student.

| ID | Risk | Probability | Impact | Mitigation |
|---|---|---|---|---|
| R01 | Student absence / insufficient work time | Medium | High | Plan daily progress, back up files, reprioritize critical path |
| R02 | Wireframe/prototype delayed | High | High | Build minimal six-feature flows first |
| R03 | GitHub setup/access problems | Medium | Medium | Verify account/repository permissions and Issues/Projects on Day 1 |
| R04 | Requirement changes / automatic email | Medium | High | Formal analysis; do not expand scope without approval |
| R05 | Prototype defects or data loss | Medium | High | Test core flows; store only fictional data; track defects |
| R06 | Missing screenshots, PRs or progress evidence | High | High | Capture dated checkpoints and link commits/Issues throughout |

## Most serious
**R06** threatens grading even if prepared documents are good: the assessment requires verifiable GitHub activity. **R02** is the largest schedule threat because prototypes and test work depend on wireframes.
