# CampusHelp — Project Charter

**Status:** Planned baseline; actual dates and progress evidence pending.

## Business problem
University students submit IT, maintenance, library and administrative service requests through emails and paper forms. These are difficult to track, assign and summarize.

## Objective
Plan, manage and demonstrate a centralized university student service request portal using GitHub Issues, milestones, a project board, risk/change control and evidence of progress.

## Measurable success criteria
1. Represent all **six mandatory capabilities** in requirements and interface designs.
2. Create and track **12 mandatory Issues**, four milestones, plus Board, Table and Roadmap GitHub Project views.
3. Demonstrate request submission, category/priority selection, unique request ID, administrator assignment, status updates and dashboard counts.
4. Execute and record at least **six** real prototype test cases.
5. Document genuine progress checkpoints on Days **2, 5 and 8**, with a final closure report.

## Stakeholders
Students, IT support staff, classroom maintenance staff, library staff, administrative staff, university management (simulated sponsor), lecturer, and solo student contributor.

## Scope
**Included:** Student submission, tracking ID, category/priority, admin assignment and status, dashboard prototype, wireframes, WBS, schedule, risk and quality plan, GitHub monitoring and final report.

**Excluded:** Production authentication, live database/server, real email/SMS, paid external services and production security/deployment.

## Constraints
One student, limited 10-day timeline, no paid external services, browser-only prototype. The original coursework was written for three students; the student confirms it is an individual assignment. No fictional team members or peer reviews will be reported.

## Acceptance
All four milestones checked; deliverables verified, limitations documented, and actual test/results and GitHub links included in the submitted PDF. Open Issues are not closed without evidence.
